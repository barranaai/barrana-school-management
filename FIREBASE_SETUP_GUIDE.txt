🔥 FIREBASE CLOUD MESSAGING - PRODUCTION SETUP GUIDE
===================================================================================

📅 Date: October 15, 2025
🎯 Purpose: Production-grade real-time push notifications
📱 Platforms: Web, iOS, Android

===================================================================================
STEP 1: CREATE FIREBASE PROJECT
===================================================================================

1. Go to: https://console.firebase.google.com/
2. Click "Add Project" or "Create a project"
3. Enter project name: "Barrana School Management"
4. Enable Google Analytics (recommended)
5. Click "Create project"

===================================================================================
STEP 2: ENABLE CLOUD MESSAGING
===================================================================================

1. In Firebase Console, go to Project Settings (gear icon)
2. Click "Cloud Messaging" tab
3. Note down these values:
   - Server Key
   - Sender ID
4. Under "Web Push certificates", click "Generate key pair"
5. Copy the "VAPID key"

===================================================================================
STEP 3: GET CONFIGURATION VALUES
===================================================================================

1. In Firebase Console → Project Settings → General
2. Scroll down to "Your apps" section
3. Click the **</> Web** icon to add a web app
4. Register app name: "Barrana Web"
5. Copy the firebaseConfig object:

const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "barrana-school.firebaseapp.com",
  projectId: "barrana-school-xxxxx",
  storageBucket: "barrana-school-xxxxx.appspot.com",
  messagingSenderId: "123456789012",
  appId: "1:123456789012:web:abc123...",
  measurementId: "G-XXXXXXXXXX"
};

===================================================================================
STEP 4: DOWNLOAD SERVICE ACCOUNT (FOR BACKEND)
===================================================================================

1. In Firebase Console → Project Settings → Service Accounts
2. Click "Generate new private key"
3. Click "Generate key" - downloads JSON file
4. Rename file to: firebase-service-account.json
5. Save to: /Users/faran/school-project/backend/config/

IMPORTANT: NEVER commit this file to git!
Add to .gitignore:
backend/config/firebase-service-account.json

===================================================================================
STEP 5: UPDATE ENVIRONMENT VARIABLES
===================================================================================

** BACKEND (.env): **

Add these to: backend/.env

# Firebase Admin SDK
FIREBASE_SERVICE_ACCOUNT_PATH=./config/firebase-service-account.json

** FRONTEND (.env.local): **

Create file: /Users/faran/school-project/.env.local

# Firebase Web Config
REACT_APP_FIREBASE_API_KEY=AIzaSy...
REACT_APP_FIREBASE_AUTH_DOMAIN=barrana-school.firebaseapp.com
REACT_APP_FIREBASE_PROJECT_ID=barrana-school-xxxxx
REACT_APP_FIREBASE_STORAGE_BUCKET=barrana-school-xxxxx.appspot.com
REACT_APP_FIREBASE_MESSAGING_SENDER_ID=123456789012
REACT_APP_FIREBASE_APP_ID=1:123456789012:web:abc123...
REACT_APP_FIREBASE_MEASUREMENT_ID=G-XXXXXXXXXX
REACT_APP_FIREBASE_VAPID_KEY=YOUR_VAPID_KEY_FROM_STEP_2

===================================================================================
STEP 6: UPDATE SERVICE WORKER CONFIG
===================================================================================

Edit: public/firebase-messaging-sw.js

Replace the firebaseConfig object with YOUR values from Step 3:

const firebaseConfig = {
  apiKey: "YOUR_API_KEY",
  authDomain: "YOUR_AUTH_DOMAIN",
  projectId: "YOUR_PROJECT_ID",
  storageBucket: "YOUR_STORAGE_BUCKET",
  messagingSenderId: "YOUR_SENDER_ID",
  appId: "YOUR_APP_ID"
};

===================================================================================
STEP 7: INITIALIZE PUSH NOTIFICATIONS IN APP
===================================================================================

The NotificationIcon component should call initializePushNotifications():

// In src/components/common/NotificationIcon.tsx
useEffect(() => {
  // Initialize FCM push notifications
  notificationService.initializePushNotifications((payload) => {
    // Handle foreground notification
    toast.success(`🔔 ${payload.notification.title}`);
    loadNotifications(); // Refresh notifications list
  });

  return () => {
    notificationService.cleanup();
  };
}, []);

===================================================================================
STEP 8: TEST PUSH NOTIFICATIONS
===================================================================================

** Test on Web: **

1. Open app: http://localhost:3000
2. Login as teacher
3. Browser will ask for notification permission → Click "Allow"
4. FCM token automatically registered

6. Close browser tab → notification should still appear!

curl -X POST http://localhost:5050/api/communication/fcm/test \

===================================================================================
STEP 9: MOBILE APP CONFIGURATION
===================================================================================

** For Android: **

1. In Firebase Console → Project Settings → General
2. Click "Add app" → Android icon
3. Enter package name: com.barrana.school
4. Download google-services.json
5. Place in: BarranaMobileApp/android/app/

** For iOS: **

1. In Firebase Console → Project Settings → General
2. Click "Add app" → iOS icon
3. Enter bundle ID: com.barrana.school
4. Download GoogleService-Info.plist
5. Place in: BarranaMobileApp/ios/

===================================================================================
STEP 10: PRODUCTION DEPLOYMENT
===================================================================================

** Hostinger VPS: **

1. Upload service account JSON:
   scp backend/config/firebase-service-account.json \
     root@191.101.233.56:/var/www/barrana/barrana-school/backend/config/

2. Update .env on server:
   ssh root@191.101.233.56
   nano /var/www/barrana/barrana-school/backend/.env
   # Add: FIREBASE_SERVICE_ACCOUNT_PATH=./config/firebase-service-account.json

3. Update frontend .env.production:
   nano /var/www/barrana/barrana-school/.env.production
   # Add all REACT_APP_FIREBASE_* variables

4. Restart backend:
   pm2 restart barrana-backend

5. Rebuild frontend:
   cd /var/www/barrana/barrana-school
   npm run build
   systemctl restart nginx
